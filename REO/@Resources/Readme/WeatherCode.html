Where to get a weather code

The Weather panel asks weather.com for your local forecast. It needs one thing from you: the location code of your city.

Option 1 - the code from a weather.com URL

  1. Open weather.com.
  2. Search for your city.
  3. Look at the address bar. After /weather/today/l/ there is a long id, for example
    1665d9e3052c3448be48dafc1587318a27ee85516e97e0b5376043cd41a4f0e8.
  4. Copy that id and paste it into the panel's Weather code setting.

Option 2 - older short codes

Codes in the form GMXX0040 (Munich), UKXX0085 (London) or USVA0944 come from the wxdata service the older skins used. weather.com still accepts them, so if you already know yours, just use it.

Option 3 - United States ZIP code

Inside the USA a ZIP code such as 22308 works as a location code.

Language and units are separate settings; changing the language also changes the units used in the forecast.

天气代码从哪来

Weather 面板向 weather.com 查询你所在城市的预报，只需要你提供一样东西：城市的位置代码。

方法一：从 weather.com 网址里取

  1. 打开 weather.com；
  2. 搜索你的城市；
  3. 看地址栏，/weather/today/l/ 后面那串长 id 就是代码，例如
    1665d9e3052c3448be48dafc1587318a27ee85516e97e0b5376043cd41a4f0e8；
  4. 把它复制到面板设置里的「天气代码」。

方法二：沿用手写短代码

GMXX0040（慕尼黑）、UKXX0085（伦敦）、USVA0944 这类短代码 来自更早的 wxdata 服务，weather.com 仍然认，知道就直接填。

方法三：美国邮编

在美国境内，邮编（如 22308）可以直接当地点代码用。

语言与单位是分开的设置；换语言会连带改变预报里使用的单位。
