## [Unreleased]

### 变更

- 安装器最低 Rainmeter 版本为 `5.0.0.5363`（Release Candidate 2）：`Rainstaller.cfg` 的 `MinRainmeterVer`、两份 README 的安装要求，以及 `Extra\` 下两个附加包的 `Rainstaller.cfg` 保持一致。
- 两份 README 新增「显示设置」一节：说明缩放或分辨率变化后布局不会自动重排，以及手动重排方式。

### Changed

- The installer requires Rainmeter `5.0.0.5363` (Release Candidate 2) or later: `MinRainmeterVer` in `Rainstaller.cfg`, the install requirements in both READMEs, and the `Rainstaller.cfg` in the two `Extra\` add-on packages.
- Both READMEs get a display settings section: the layout does not reflow after a scaling or resolution change, and how to rearrange it.
